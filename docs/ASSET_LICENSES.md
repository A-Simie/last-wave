### Kiroween hackathon

The game is free and not sold. Entering a contest with prizes is still arguably commercial use under the NC licences. Two safe options:

1. **Submit the `commercial` policy build** with the five NC files removed from `dist/`. The game stays complete because every NC asset has a licence-safe substitute.
2. Or keep the `full` build and **ask each NC author for written permission**: ArachnoBoy (bat), VRC-IW (bus), Alex.Ka. (pickup), CGV (yellow umbrella) and Adam Homoki (goblet). Each can be contacted through their Sketchfab profile. Store any replies in `asset-library/permissions/`.

Also check the Kiroween rules for anything they say about third-party asset licences.

## 5. Re-checking or adding files

1. Put new downloads in `New FIles/`. It is git-ignored, so keep the originals there or archive them in `asset-library/`.
2. Read the embedded licence. If a file has no `asset.extras.license`, look up its source page before using it.
3. Add an entry to `MODELS` in `scripts/prepare-new-assets.mjs`. Use `{ verbatim: true }` for any ND licence.
4. Install the tooling outside the repository (see the handoff), then run `node scripts/prepare-new-assets.mjs <tool-dir>` followed by `node scripts/generate-model-catalog.mjs`.
5. Add the row here and in `credits.html`, then run `pnpm test`. `tests/new-assets.test.mjs` fails if a catalogued file is missing, its size changed, or an ND file was modified.
